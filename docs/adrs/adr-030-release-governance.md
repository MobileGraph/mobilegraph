# ADR-030: Release Management and Governance Model

## Status
Accepted

## Context
An open-source framework used by many applications needs a clear governance model, release cadence, and contribution process to remain healthy and trustworthy.

## Decision
- Release cadence: Minor versions quarterly; patch releases as needed; major versions annually maximum
- Governance: Steering committee of 5 members (3 core maintainers + 2 community representatives)
- RFC process: All significant API changes require an RFC document with 2-week community review period
- License: Apache 2.0 for all core modules
- Contribution: Contributions require DCO (Developer Certificate of Origin) sign-off.
